# Zoho Japan

このリポジトリは、今後さまざまな製品およびユースケースを追加できるように構成されています。

## リポジトリ構成

- [common](common): 製品横断で再利用するドキュメントおよびアセットを格納します。
- [crm](crm): CRM向けの製品別ユースケース、スクリプト、ドキュメントを格納します。

## 製品・ユースケース一覧
