1. Go to `Setup > Developer Hub > Client Script`.
![](media/step-1.png)
2. Click on the "New Script" button and input required details.
![](media/step-2.png)
    - Name
        - Any name to identify the script
    - Description
        - Brief description about the script
    - Category
        - Module : In case the script needs to be triggered on a particular module.
        - Commands : In case the script needs to be triggered from the Command.
    - Page
        - Options like Create/Edit/Detailed/Clone page.
    - Module
        - Select the CRM module for which the script needs to be triggered.
    - Layout
        - Select the layout for which the script needs to be triggered on the selected module.
    - Canvas : (Page = Canvas/Mobile Canvas)
        - Select the canvas for which the script needs to be triggered.
    - Type
        - Page Event : Trigger the script based on event happening on the page like onLoad/ onSave/ onChange
        - Field Event - Trigger the script based on change in value of a particular field.
        - Subform Event - Trigger the script based on event happening on the subform.
    - Field (In case of Field event)
        - Select the field for which the script needs to be triggered.
    - Subform (In case of Subform event)
        - Select the subform for which the script needs to be triggered.
    - Event
       - Event of the selected type.
3. Click on "Next" button to open the script editor.

4. Write the script in the editor.
![](media/step-4.png)

5. Add Static resources if the script has any dependencies which is already uploaded under `CRM Setup > Developer Space > Client Script > Static Resources`.
![](media/step-5.png)

6. In case if editing the existing function Review tab will be accessible where you can see the changes done in the script with respect to the previous version.
![](media/step-6.png)

7. Revisions tab will have the history of all the changes done to the script with details like version number, date of modification and person who modified it. Clicking on `Use this revision` button will take you to the script editor with the selected version of the script where you can edit and save it as a new version.
![](media/step-7.png)

8. Test run page will allow user to handle the execution of the script and see the logs generated by the script in real time which will be helpful in debugging the script.


> **IMPORTANT** : <span style="color:red">Data changes done in this testing will be reflected in the CRM, so it is recommended to use a test CRM record for testing the script.</span>

9. Give meaningful commit message for future reference and click on "Save" button to save the script.
![](media/step-8.png)
